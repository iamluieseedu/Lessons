Eloquent ORM: Fresh Project, Table Schemas, Models & Dynamic Blade Queries

In this laboratory phase, build a persistent, dynamic database application in a brand-new Laravel 11 project. Master Laravel's Eloquent ORM, table schemas with Artisan, mass-assignment safety with $fillable, test data seeding, and dynamic Blade rendering.

Fresh Project Notice: You will create a brand-new, independent Laravel 11 project (campus-gear) for this activity. You do not need to migrate or carry over code from your previous laboratory tasks.

Learning Objectives

Fresh Project Setup: Scaffold a brand-new Laravel 11 application (composer create-project) dedicated solely to database operations.
Table Schemas: Design structured database tables using Artisan schema files with typed columns.
Eloquent Models: Generate model classes and configure $fillable mass-assignment protection.
Database Seeders: Populate mock datasets and verify queries inside the php artisan tinker REPL.

Step 1: Scaffold a Brand-New Laravel 11 Project

In your terminal or command prompt, generate a fresh Laravel 11 project named campus-gear:

Terminal 
composer create-project laravel/laravel campus-gear
cd campus-gear

Open this new folder in VS Code (code .) to begin.

Step 2: Environment & Database Config

Ensure your .env file specifies SQLite (zero setup) or MySQL:

.env 
DB_CONNECTION=sqlite

Step 3: Creating the Products Table Schema

Terminal 
php artisan make:migration create_products_table --create=products

Open database/migrations/xxxx_xx_xx_create_products_table.php:

database/migrations/xxxx_xx_xx_create_products_table.php 
Schema::create('products', function (Blueprint $table) {
    $table->id();
    $table->string('name');
    $table->string('sku')->unique();
    $table->string('category');
    $table->decimal('price', 8, 2);
    $table->integer('stock')->default(0);
    $table->text('description')->nullable();
    $table->boolean('is_available')->default(true);
    $table->timestamps();
});

Step 4: Running Table Schemas & Generating Model

Terminal 
php artisan migrate
php artisan make:model Product

In app/Models/Product.php, configure $fillable:

app/Models/Product.php 
protected $fillable = [
    'name',
    'sku',
    'category',
    'price',
    'stock',
    'description',
    'is_available'
];

Step 5: Master Layout & Dynamic Blade View

In your new project, create resources/views/layouts/app.blade.php:

resources/views/layouts/app.blade.php 
<!DOCTYPE html>
<html lang="en">
<head>
    <title>@yield('title', 'Campus Gear')</title>
</head>
<body>
    <div class="container">@yield('content')</div>
</body>
</html>

Then create resources/views/products/index.blade.php extending layouts.app and looping over @forelse($products as $product).
