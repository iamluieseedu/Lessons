Eloquent ORM: Migrations, Models, Database Seeding & Dynamic Blade Queries

In this laboratory phase, transition your application from static templates to full persistent database operations. Master Laravel 11's Eloquent ORM (ActiveRecord pattern), schema migrations, mass-assignment safety with $fillable, test data seeding, and dynamic Blade rendering.

Learning Objectives

Schema Migrations: Design structured table schemas using Artisan migrations with typed columns.
Eloquent Models: Generate model classes and configure $fillable mass-assignment protection.
Database Seeders: Populate mock datasets and verify queries inside the php artisan tinker REPL.
Dynamic Blade CRUD: Query database records with Eloquent methods and render them dynamically in Blade.

Step 1: Environment & Database Config

Ensure your .env file specifies SQLite (zero setup) or MySQL:

.env 
DB_CONNECTION=sqlite

Step 2: Creating the Products Migration

Terminal 
php artisan make:migration create_products_table --create=products

Open database/migrations/xxxx_xx_xx_create_products_table.php:

database/migrations/xxxx_xx_xx_create_products_table.php 
Schema::create('products', function (Blueprint $table) {
    $table->id();
    $table->string('name');
    $table->string('sku')->unique();
    $table->string('category');
    $table->decimal('price', 8, 2);
    $table->integer('stock')->default(0);
    $table->text('description')->nullable();
    $table->boolean('is_available')->default(true);
    $table->timestamps();
});

Step 3: Running Migrations & Generating Model

Terminal 
php artisan migrate
php artisan make:model Product

In app/Models/Product.php, configure $fillable:

app/Models/Product.php 
protected $fillable = [
    'name',
    'sku',
    'category',
    'price',
    'stock',
    'description',
    'is_available'
];
