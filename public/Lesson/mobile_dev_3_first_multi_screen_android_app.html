Screen Navigation & Design Architecture

Your application consists of clean visual screens. Navigation is 100% event-driven: clicking any action button fires a Kotlin setOnClickListener event that tells the Android OS to open the requested screen. No login credentials, database, or password validation needed!

Setup Colors, Strings & Adding an Image to Drawable

Configure your project's color palette, localized text strings, and learn how to add your own custom image file (PNG / JPG) into Android Studio.

How to Add an Image (PNG / JPG) in Android Studio
1
Prepare your image on your computer:

Pick any image or logo on your computer and save or rename it as logo.png (or app_logo.png).

Android Rule: File names in res/drawable must be strictly lowercase and have no spaces (e.g. logo.png, NOT Logo.png or my logo.png).
2
Copy the image file:

In Windows File Explorer, click your image file and press Ctrl + C.

3
Paste into Android Studio:

In Android Studio's left Project panel, expand app > src > main > res. Right-click the drawable folder and select Paste (Ctrl + V).

4
Select Destination Directory:

If a popup asks to choose a destination, select the standard .../res/drawable folder (do NOT choose drawable-v24) and click OK.

5
How to display it in XML:

In any layout file, simply use an <ImageView> tag with android:src="@drawable/logo"!

package com.example.campusconnect

import android.content.Intent
import androidx.appcompat.app.AppCompatActivity
import android.os.Bundle
import android.widget.Button

class MainActivity : AppCompatActivity() {

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main)

        // 1. Locate buttons in the XML layout
        val btnEnterDashboard = findViewById<Button>(R.id.btnEnterDashboard)
        val btnLogin = findViewById<Button>(R.id.btnLogin)
        val btnSignUp = findViewById<Button>(R.id.btnSignUp)

        // 2. Direct button navigation to Dashboard!
        btnEnterDashboard.setOnClickListener {
            val intent = Intent(this, DashboardActivity::class.java)
            startActivity(intent)
        }

        // 3. Navigation to Login Screen
        btnLogin.setOnClickListener {
            val intent = Intent(this, LoginActivity::class.java)
            startActivity(intent)
        }

        // 4. Navigation to Sign Up Screen
        btnSignUp.setOnClickListener {
            val intent = Intent(this, SignUpActivity::class.java)
            startActivity(intent)
        }
    }
}

package com.example.campusconnect

import android.content.Intent
import androidx.appcompat.app.AppCompatActivity
import android.os.Bundle
import android.widget.Button
import android.widget.LinearLayout
import android.widget.Toast

class DashboardActivity : AppCompatActivity() {

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_dashboard)

        // 1. Locate UI elements
        val cardProfile = findViewById<LinearLayout>(R.id.cardProfile)
        val cardCourses = findViewById<LinearLayout>(R.id.cardCourses)
        val cardSettings = findViewById<LinearLayout>(R.id.cardSettings)
        val btnReturnHome = findViewById<Button>(R.id.btnReturnHome)
        val btnSwitchToLogin = findViewById<Button>(R.id.btnSwitchToLogin)

        // 2. Card click feedback events
        cardProfile.setOnClickListener {
            Toast.makeText(this, "Profile: IT Student", Toast.LENGTH_SHORT).show()
        }

        cardCourses.setOnClickListener {
            Toast.makeText(this, "Enrolled: Mob Dev 1 Lab", Toast.LENGTH_SHORT).show()
        }

        cardSettings.setOnClickListener {
            Toast.makeText(this, "Settings: Arctic Fox 2020.3.1", Toast.LENGTH_SHORT).show()
        }

        // 3. Return to Welcome Screen
        btnReturnHome.setOnClickListener {
            val intent = Intent(this, MainActivity::class.java)
            intent.flags = Intent.FLAG_ACTIVITY_NEW_TASK or Intent.FLAG_ACTIVITY_CLEAR_TASK
            startActivity(intent)
        }

        // 4. Switch to Login Screen
        btnSwitchToLogin.setOnClickListener {
            startActivity(Intent(this, LoginActivity::class.java))
        }
    }
}

import android.content.Intent

        // 3. Return to Welcome screen
        btnBack.setOnClickListener {

        }
    }

Quick Troubleshooting Guide

ActivityNotFoundException

App crashes when clicking a button.

Fix: Open AndroidManifest.xml and confirm the activity is registered inside <application>.
Image Won't Show or Build Error

Error: "Resource entry ... is not a valid resource name".

Fix: Ensure your image file name is strictly lowercase with NO spaces (e.g. logo.png, NOT Logo.png).
"Unresolved reference: R"

Kotlin files highlight R.id... in red.

Fix: Check top imports. If you see import android.R, delete it! Then click Build > Clean Project.
Button clicks do nothing

Touching button does not open screen.

Fix: Confirm button.setOnClickListener { ... } is written inside onCreate(), after setContentView().
