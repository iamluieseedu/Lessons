Building Your First Multi-Screen Android Application

Welcome Screen → Login → Sign Up → Personalized Dashboard → Logout

In this hands-on laboratory, you will build a complete 4-screen native Android application in Android Studio Arctic Fox (2020.3.1) using Kotlin and XML Layouts. You will connect multiple screens, manage Activity lifecycles, pass user data across screens using explicit Intent extras, and implement secure back-stack clearance on logout.

IDE: Android Studio Arctic Fox | 2020.3.1
Language: Kotlin
UI Engine: XML Layouts
Min SDK: API 21 (Android 5.0)
Duration: 90 - 120 Mins
Step-by-Step Lab Navigation
Screen Flow Map 1. Project Setup 2. Design Resources 3. Welcome Screen 4. Login Screen 5. Sign Up Screen 6. Dashboard & Logout 7. AndroidManifest 8. Run & Checklist Troubleshooting

Application Screen Flow Map

Your application consists of 4 distinct screens. In Android, each screen is represented by an Activity (Kotlin logic) paired with an XML layout (visual user interface). Screens communicate and navigate via explicit Intents.

Screen 1 • Launcher MainActivity.kt

Welcome Screen

First screen seen when opening the app. Shows logo, portal title, and entry navigation buttons.

LOG IN → Opens LoginActivity
SIGN UP → Opens SignUpActivity
Screen 2 • Auth LoginActivity.kt

Login Screen

Captures username and password. Validates against demo credentials (admin / 1234).

LOG IN → Passes username to Dashboard
SIGN UP → Jumps to SignUpActivity
Screen 3 • Register SignUpActivity.kt

Sign Up Screen

Registration form with input validation (checks for empty fields and confirms passwords match).

SUBMIT → Passes Full Name to Dashboard
LOG IN → Jumps to LoginActivity
Screen 4 • Home Portal DashboardActivity.kt

Dashboard Screen

Displays personalized greeting with student name, interactive course cards, and secure logout.

LOG OUT → Clears Back Stack → Welcome
Pressing Android Back button will NOT reopen dashboard!

How Data Moves Between Screens (Intent Extras)

Key-Value Pair Contract
1. Sender (Login or Sign Up) Packs the username into the Intent: intent.putExtra("USER_NAME", name)
2. Receiver (DashboardActivity) Reads the name using the exact matching key: val name = intent.getStringExtra("USER_NAME")

Step 4.2: Login Logic & Auth Check
File to Edit: app > src > main > java > com.example.campusconnect > LoginActivity.kt
LoginActivity.kt 
package com.example.campusconnect

import android.content.Intent
import androidx.appcompat.app.AppCompatActivity
import android.os.Bundle
import android.widget.Button
import android.widget.EditText
import android.widget.Toast

class LoginActivity : AppCompatActivity() {

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_login)

        // 1. Locate Views
        val etUsername = findViewById<EditText>(R.id.etLoginUsername)
        val etPassword = findViewById<EditText>(R.id.etLoginPassword)
        val btnLogin = findViewById<Button>(R.id.btnPerformLogin)
        val btnGoToSignUp = findViewById<Button>(R.id.btnGoToSignUp)
        val btnBackToWelcome = findViewById<Button>(R.id.btnBackToWelcome)

        // 2. Perform Login with Validation
        btnLogin.setOnClickListener {
            val username = etUsername.text.toString().trim()
            val password = etPassword.text.toString().trim()

            if (username.isEmpty()) {
                etUsername.error = "Please enter your username"
                etUsername.requestFocus()
                return@setOnClickListener
            }

            if (password.isEmpty()) {
                etPassword.error = "Please enter your password"
                etPassword.requestFocus()
                return@setOnClickListener
            }

            // Demo Credentials Check: admin / 1234
            if (username == "admin" && password == "1234") {
                Toast.makeText(this, "Login successful! Welcome, $username", Toast.LENGTH_SHORT).show()
                
                // Open Dashboard and pass the username extra!
                val intent = Intent(this, DashboardActivity::class.java)
                intent.putExtra("USER_NAME", username)
                startActivity(intent)
                finish() // Finish login screen so user cannot back into it
            } else {
                Toast.makeText(this, "Invalid credentials! Use admin / 1234", Toast.LENGTH_LONG).show()
            }
        }

        // 3. Switch to Sign Up screen
        btnGoToSignUp.setOnClickListener {
            val intent = Intent(this, SignUpActivity::class.java)
            startActivity(intent)
            finish()
        }

        // 4. Return to Welcome screen
        btnBackToWelcome.setOnClickListener {
            finish()
        }
    }
}

Step 5.2: Sign Up Validation Logic
File to Edit: app > src > main > java > com.example.campusconnect > SignUpActivity.kt
SignUpActivity.kt 
package com.example.campusconnect

import android.content.Intent
import androidx.appcompat.app.AppCompatActivity
import android.os.Bundle
import android.widget.Button
import android.widget.EditText
import android.widget.Toast

class SignUpActivity : AppCompatActivity() {

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_sign_up)

        // 1. Locate Views
        val etName = findViewById<EditText>(R.id.etSignUpName)
        val etEmail = findViewById<EditText>(R.id.etSignUpEmail)
        val etPassword = findViewById<EditText>(R.id.etSignUpPassword)
        val etConfirmPassword = findViewById<EditText>(R.id.etSignUpConfirmPassword)
        val btnSignUp = findViewById<Button>(R.id.btnPerformSignUp)
        val btnGoToLogin = findViewById<Button>(R.id.btnGoToLogin)
        val btnBack = findViewById<Button>(R.id.btnBackFromSignUp)

        // 2. Form Validation & Registration
        btnSignUp.setOnClickListener {
            val name = etName.text.toString().trim()
            val email = etEmail.text.toString().trim()
            val password = etPassword.text.toString().trim()
            val confirmPassword = etConfirmPassword.text.toString().trim()

            if (name.isEmpty()) {
                etName.error = "Please enter your full name"
                etName.requestFocus()
                return@setOnClickListener
            }

            if (email.isEmpty() || !email.contains("@")) {
                etEmail.error = "Please enter a valid email"
                etEmail.requestFocus()
                return@setOnClickListener
            }

            if (password.length < 6) {
                etPassword.error = "Password must be at least 6 characters"
                etPassword.requestFocus()
                return@setOnClickListener
            }

            if (password != confirmPassword) {
                etConfirmPassword.error = "Passwords do not match!"
                etConfirmPassword.requestFocus()
                return@setOnClickListener
            }

            // Success! Pass Full Name to DashboardActivity
            Toast.makeText(this, "Registration Successful!", Toast.LENGTH_SHORT).show()
            val intent = Intent(this, DashboardActivity::class.java)
            intent.putExtra("USER_NAME", name)
            startActivity(intent)
            finish()
        }

        // 3. Switch to Login screen
        btnGoToLogin.setOnClickListener {
            val intent = Intent(this, LoginActivity::class.java)
            startActivity(intent)
            finish()
        }

        // 4. Return to Welcome screen
        btnBack.setOnClickListener {
            finish()
        }
    }
}

Step 6.2: Read Extra & Back-Stack Clearance
File to Edit: app > src > main > java > com.example.campusconnect > DashboardActivity.kt
DashboardActivity.kt 
package com.example.campusconnect

import android.content.Intent
import androidx.appcompat.app.AppCompatActivity
import android.os.Bundle
import android.widget.Button
import android.widget.LinearLayout
import android.widget.TextView
import android.widget.Toast

class DashboardActivity : AppCompatActivity() {

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_dashboard)

        // 1. Locate UI elements
        val tvGreeting = findViewById<TextView>(R.id.tvDashboardGreeting)
        val cardProfile = findViewById<LinearLayout>(R.id.cardProfile)
        val cardCourses = findViewById<LinearLayout>(R.id.cardCourses)
        val cardSettings = findViewById<LinearLayout>(R.id.cardSettings)
        val btnLogout = findViewById<Button>(R.id.btnLogout)

        // 2. Extract passed user name from Intent extras
        val passedUserName = intent.getStringExtra("USER_NAME")
        val displayName = if (!passedUserName.isNullOrEmpty()) passedUserName else "Student"
        tvGreeting.text = "Welcome, $displayName!"

        // 3. Interactive card feedback
        cardProfile.setOnClickListener {
            Toast.makeText(this, "Profile: Logged in as $displayName", Toast.LENGTH_SHORT).show()
        }

        cardCourses.setOnClickListener {
            Toast.makeText(this, "Courses: 4 enrolled lab subjects active", Toast.LENGTH_SHORT).show()
        }

        cardSettings.setOnClickListener {
            Toast.makeText(this, "Settings: CampusConnect v1.0", Toast.LENGTH_SHORT).show()
        }

        // 4. LOGOUT: Clears intermediate activities from the task stack!
        btnLogout.setOnClickListener {
            val intent = Intent(this, MainActivity::class.java)
            // Critical: FLAG_ACTIVITY_NEW_TASK | FLAG_ACTIVITY_CLEAR_TASK clears the stack
            intent.flags = Intent.FLAG_ACTIVITY_NEW_TASK or Intent.FLAG_ACTIVITY_CLEAR_TASK
            startActivity(intent)
            finish()
        }
    }
}

Quick Troubleshooting Guide

ActivityNotFoundException

App crashes when clicking a button.

Fix: Open AndroidManifest.xml and confirm the activity is registered inside <application>.
"Unresolved reference: R"

Kotlin files highlight R.id... in red.

Fix: Check top imports. If you see import android.R, delete it! Then click Build > Clean Project.
Dashboard says "Welcome, Student!"

Passed name is not displaying.

Fix: Keys must match exactly: putExtra("USER_NAME", name) ↔ getStringExtra("USER_NAME").
Button clicks do nothing

Touching button does not open screen.

Fix: Confirm button.setOnClickListener { ... } is written inside onCreate(), after setContentView().
