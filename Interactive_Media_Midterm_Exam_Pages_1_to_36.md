**B. The 6 Core Components of an Interactive System:**
1. **User** (Human agent na may layunin at mental model)
2. **Input** (Hardware na nagsasalin ng galaw ng tao tulad ng mouse/keyboard/touch)
3. **Interface** (Visual membrane tulad ng screen graphics at audio)
4. **System** (Computational processor, database, at business logic)
5. **Output** (Mga visual pixel, tunog, o haptic vibration na ipinapakita)
6. **Feedback** (Agarang kumpirmasyon na natanggap at naiproseso ang aksyon)

**C. The 3 System Response Time Thresholds:**
1. **0.1 Segundo (100ms)** — Nararamdaman ng user na "instantaneous" ang reaksyon (button clicks).
2. **1.0 Segundo** — Hindi napuputol ang "flow of thought" ng user; sapat para sa mabilisang page transition.
3. **10.0 Segundo** — Limitasyon ng focus at atensyon ng tao; mandatory ang progress bar upang hindi mag-quit ang user.

### PART V: RUBRIC & ESSAY KEY CONCEPTS
- **Item 1 (Gulfs):** Execution = paano gagawin; Evaluation = ano ang nangyari. Ayusin sa pamamagitan ng visual signifiers at immediate loading feedback.
- **Item 2 (Deconstruction):** User (manonood/cardholder), Input (tap/PIN pad), Interface (controls/screen), System (server/banking network), Output (video display/cash slot), Feedback (scrubber bar/receipt prompt).
- **Item 3 (Agency vs Automation):** Dapat manatiling may hawak ng desisyon ang tao; ang labis na automation (forced restart o silent deletion) ay nagdudulot ng galit at pagkasira ng gawa.
- **Item 4 (Kiosk Design):** Malalaking targets (48x48px+) para maiwasan ang fat-finger error; high contrast para sa sunlight glare sa lobby; 60s timeout para protektahan ang record ng estudyante.
